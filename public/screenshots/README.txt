Drop your real screenshots here with these exact filenames, and they'll
automatically appear on the landing page — no code changes needed:

  dashboard.png       — your Dashboard page
  opportunities.png   — the Opportunities list
  applications.png    — your Applications / tracking page
  calendar.png        — the Calendar page

You don't need all four — any that exist will show up, any that don't
are simply skipped. PNG or JPG both work (just keep the .png extension
in the filename either way, or update ScreenshotsSection.tsx if you'd
rather use .jpg).

Tip: crop tightly to the actual app content (no browser chrome/tabs)
for the cleanest look.
